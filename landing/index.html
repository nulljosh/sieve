Connect Gmail and sieve reads your inbox, scores the junk, and clears it in one tap — real unsubscribe, not a filter rule. No screenshots, no manual clicking.

This is the iPhone app, live. Try it.

A real inbox app — web, iOS, macOS — plus a Claude Code skill for the dev-tool-alert half of the job. Nothing gets touched until you tap it.

Real alerts

App Store Connect, Vercel, Sentry, GitHub Actions, matched to the project, checked against its roadmap and memory, fixed on the spot or filed.

Spam scoring

Domain mismatch, urgency language, obfuscated links, unsubscribe headers from senders nobody asked for. Two signals confirms junk.

One-click unsubscribe

POSTs straight to the sender's RFC 8058 endpoint where supported. No browser, no click-through, no confirmation page.

Dry run by default

Every run reads and classifies first. Deleting or archiving is a separate, explicit pass.
